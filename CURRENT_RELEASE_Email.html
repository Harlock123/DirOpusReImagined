DirOpus Reimagined v0.1.34.0
A fast, cross-platform dual-panel file manager — inspired by the classic Amiga Directory Opus.

Hi! I've been building a file manager and just released a new version — thought you might like to try it. It runs on Windows, macOS, and Linux (Intel & ARM), it's free and open source, and there's nothing to install — just unzip and run.

What it does
  • Two folders side by side — copy, move, and compare between them, with folder tabs on each side.
  • All the file basics — copy / move / rename / delete, drag-and-drop, copy and paste with other file managers, delete-to-Trash (recoverable), and undo for renames, moves and deletes.
  • Compare & sync two folders with a click, compare two files side by side, and find duplicates.
  • Cloud storage built in — Google Drive, OneDrive, Dropbox, Amazon S3, and 50+ more, browsed like local folders.
  • Archives like folders — open .zip, .7z, .rar, and .tar, copy files into, rename and delete inside .zip and .tar archives, and save edits back into them — even archives inside archives.
  • Batch rename — rename a whole selection with a live before→after preview, find&replace (regex), and numbering.
  • Make it yours — banks of 36 custom buttons to launch your own tools, plus bookmarks and a built-in file viewer.
  • Themes — Light/Dark, Dracula, Nord, and Solarized.
  • Fast to drive — search by name or by what’s inside files, recent folders, flat view, a command palette, type-ahead jumping, and full keyboard control with your own shortcuts.
New in 0.1.34:
  • Copy and paste with other file managers — Ctrl+C / Ctrl+V files between DORI and Explorer, Finder or Files, with cut-to-move too.
  • Folder rules — tidy a folder automatically: move, copy, trash, label or tag files by name and age, by hand or as they arrive.
  • Disk catalogues — keep a record of an external drive or cloud remote, browse and search it while it’s unplugged, and see what changed.
  • Archives inside archives — open a .zip inside a .tar.gz (or any mix), and changes can be saved back into the outer archive.
  • Speed limit and Start Later — cap how fast copies run, and hold the queue until a time like 2am.
  • Folder sizes that stay — measure folders (Ctrl+Shift+S), sort them by size, and see them in the selection total.
  • Natural sort — file2 now comes before file10.
  • Video thumbnails — videos show a frame as their thumbnail and in the preview, when ffmpeg is installed.
  • Export a listing — save a panel’s files as CSV, text or a web page.
  • Securely delete — overwrite files before deleting them, for sensitive files.
  • Earlier, in 0.1.28 to 0.1.33: disk usage, labels and tags, a git status column, image tools, saving edits back into archives, synced browsing, copies that carry on, splitting and joining files, undo for deletes, renames and moves, comparing two files, flat view, finding duplicates, the command palette, saved layouts and filters, your own shortcuts, dates and permissions, photo details, writing into .zip and .tar archives, search inside files, banks of buttons and checksums.
Fixed: since 0.1.19, copying or moving to and from cloud folders, and copying or moving files out of archives, didn’t work. 0.1.28 fixed that, and 0.1.29 fixes a stray line left around the active panel after resizing the window, and button labels cut off in small windows.
