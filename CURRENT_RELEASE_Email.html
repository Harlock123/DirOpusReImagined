DirOpus Reimagined v0.1.33.0
A fast, cross-platform dual-panel file manager — inspired by the classic Amiga Directory Opus.

Hi! I've been building a file manager and just released a new version — thought you might like to try it. It runs on Windows, macOS, and Linux (Intel & ARM), it's free and open source, and there's nothing to install — just unzip and run.

What it does
  • Two folders side by side — copy, move, and compare between them, with folder tabs on each side.
  • All the file basics — copy / move / rename / delete, drag-and-drop, delete-to-Trash (recoverable), and undo for renames, moves and deletes.
  • Compare & sync two folders with a click, compare two files side by side, and find duplicates.
  • Cloud storage built in — Google Drive, OneDrive, Dropbox, Amazon S3, and 50+ more, browsed like local folders.
  • Archives like folders — open .zip, .7z, .rar, and .tar, copy files into, rename and delete inside .zip and .tar archives, and save edits back into them.
  • Batch rename — rename a whole selection with a live before→after preview, find&replace (regex), and numbering.
  • Make it yours — banks of 36 custom buttons to launch your own tools, plus bookmarks and a built-in file viewer.
  • Themes — Light/Dark, Dracula, Nord, and Solarized.
  • Fast to drive — search by name or by what’s inside files, recent folders, flat view, a command palette, type-ahead jumping, and full keyboard control with your own shortcuts.
New in 0.1.33:
  • Disk usage — see what takes the space under a folder, largest first with bars, and dig into any folder.
  • Labels and tags — colour files and folders, tag them, and filter a panel by tag.
  • Git status — a column showing which files are modified, new or ignored inside a git repository.
  • Image tools — shrink, convert (JPEG, PNG, WebP) and turn a batch of pictures, and stand sideways photos upright for good.
  • Edits saved back into archives — open a file from a .zip or .tar in another program, save it, and DORI offers to put it back.
  • Synced browsing — “Follow” takes the other panel into the folder of the same name as you browse.
  • Copies that carry on — a large copy that was cancelled or failed continues where it stopped, and Verify copies now checks archives too.
  • Split and join files — cut a big file into pieces of any size, and join them back with a checksum check.
  • Buttons that ask — a custom button can ask for a value (a commit message, a file name) before it runs.
  • Earlier, in 0.1.28 to 0.1.32: undo for deletes, renames and moves, comparing two files, flat view, finding duplicates, the command palette, saved layouts and filters, your own shortcuts, dates and permissions, photo details, writing into .zip and .tar archives, search inside files, banks of buttons and checksums.
Fixed: since 0.1.19, copying or moving to and from cloud folders, and copying or moving files out of archives, didn’t work. 0.1.28 fixed that, and 0.1.29 fixes a stray line left around the active panel after resizing the window, and button labels cut off in small windows.
